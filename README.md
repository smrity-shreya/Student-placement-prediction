---

## 📌 Project Objective

Predict whether a student will receive a campus placement offer (**Placed = 1** / **Not Placed = 0**) based on five academic and profile features: CGPA, number of internships, number of projects, technical skills score, and active backlogs.

The project demonstrates a full, production-style ML pipeline — from synthetic data generation through EDA, model training, evaluation, artefact serialisation, and deployment as an interactive Streamlit web app.

## ⚙️ Setup & Run Instructions

### Prerequisites

Make sure Python 3.10 or higher is installed. Then install the required packages:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn streamlit
```

---

### Step 1 — Generate the Synthetic Dataset

```bash
python generate_dataset.py
```

✅ This creates **`placement_data.csv`** with 1,000 realistic student records.

---

### Step 2 — Run EDA and Train the Models

```bash
python eda_and_modeling.py
```

✅ This script:
- Prints missing-value checks and descriptive statistics
- Saves four EDA/evaluation plots as `.png` files
- Trains and compares **Logistic Regression** and **Random Forest**
- Prints Accuracy, Confusion Matrix, and Classification Report for both
- Saves **`placement_model.pkl`** (Random Forest) and **`scaler.pkl`**

---

### Step 3 — Launch the Streamlit Web App

Ensure `placement_model.pkl` and `scaler.pkl` are in the **same folder** as `app.py`, then run:

```bash
streamlit run app.py
```

Your default browser will open automatically at `http://localhost:8501`.

Use the sliders and dropdowns to enter a student profile and click **"Predict Placement Status"** to get an instant prediction with probability score.

## 📊 Key Insights from EDA

- **CGPA** is the single strongest predictor of placement (highest feature importance).
- **Internships** rank second — practical experience significantly boosts placement odds.
- **Core Backlogs** have a strong *negative* correlation with placement probability.
- The CGPA distribution plot clearly shows placed students cluster above 7.5 CGPA.
